# 🥣 Digital Katora

> **Paise Chahiye? Katora Uthao!** — The Viral Desi Micro-Donation & Social Tipping Platform.

Digital Katora is a playful, meme-powered social micro-tipping community web application. Drop coins, earn punya, and fund your broken friends!

---

## ✨ Features

- 🥣 **Create Your Katora**: Set up custom tip jars with hilarious goals and reasons.
- 🪙 **Interactive Coin Dropping**: Fun, physics-inspired donation animations and sound effects.
- 🏺 **Punya Ka Ghada**: Track your good deeds and karmic leaderboard.
- 🏆 **Achievements & Badges**: Unlock comedic milestones as a donor or beggar.
- 📊 **Live Leaderboard & Statistics**: See top donors and viral katoras across the platform.
- 🎨 **Modern Desi Cyberpunk / Neo-Pop UI**: Responsive, dark-mode first design with smooth micro-interactions.

---

## 🚀 Getting Started

Simply open `digital-katora/index.html` in your favorite web browser or serve it using any static web server:

```bash
# Using Python
python -m http.server 8000 --directory digital-katora

# Using Node (serve / http-server / live-server)
npx serve digital-katora
```

Then visit `http://localhost:8000` in your browser.
